NcatBot 示例插件

约 1194 字大约 4 分钟

按平台分类的示例插件集合，覆盖框架全部核心功能和常见用户场景。 每个插件都可以直接复制到 plugins/ 目录中运行。

目录

common/ — 通用框架特性（跨平台通用）

不依赖任何特定平台，使用纯 Trait 编程和 registrar.on_*() 通用装饰器。

#插件演示功能难度
01hello_worldNcatBotPlugin 基类、Trait 回复、跨平台命令、参数绑定 vs 手动解析⭐
02config_and_dataConfigMixin / DataMixin 持久化⭐
03hook_and_filterHook 系统（BEFORE/AFTER/ON_ERROR）、add_hooks⭐⭐
04rbacRBAC 权限管理（角色/权限/检查）⭐⭐
05scheduled_tasks定时任务（多种时间格式/条件执行）⭐⭐
06external_api外部 API 集成（aiohttp/配置/错误处理）⭐⭐
07command_group命令组分层路由（CommandGroupHook/子命令/参数绑定）⭐⭐
08dispatch_filterDispatchFilterMixin 群/用户/命令级禁用管理⭐⭐
09plugin_management插件动态加载、卸载、生命周期状态持久化⭐⭐

qq/ — QQ 平台专属

使用 registrar.qq.* 平台子注册器和 QQ 专用事件/API。

基础层（01-07）：建立命令、事件、消息、会话的核心心智模型。

#插件演示功能难度
01event_registration事件注册方式（on_command/on_message/on_notice/on_request/priority/ignore_case）⭐
02command_binding命令参数绑定（str/int/float/At/Reply/Image/Optional/aliases/shlex）⭐
03rich_message富文本消息三路径（MessageArray/Sugar/底层 API）⭐
04forward_message合并转发（ForwardConstructor/set_author/嵌套转发）⭐
05notice_and_request通知与请求事件（入群/退群/撤回/戳/表情回应/好友/群请求）⭐⭐
06session_basics会话等待与过滤（wait_session_reply/SessionResult/谓词组合）⭐⭐
07dialog_and_menu多步对话与菜单（session_prompt/session_choose/嵌套菜单）⭐⭐

场景层（08-11）：用完整小助手串联真实使用场景。

#插件演示功能难度
08receive_attachment消息解析与附件处理（filter/Attachment/download/is_at）⭐⭐
09group_admin群管理助手（踢/禁言/名片/头衔/公告/精华/RBAC）⭐⭐⭐
10info_query信息查询助手（群/成员/消息/好友/公告/精华）⭐⭐
11file_and_folder文件上传与群文件夹管理（upload/download/folder/转存）⭐⭐⭐

bilibili/ — Bilibili 平台专属

使用 registrar.bilibili.* 平台子注册器和 Bilibili 专用事件/API。

#插件演示功能难度
01hello_world弹幕 + 私信基础响应⭐
02live_room直播间全事件（弹幕/SC/礼物/大航海/互动）⭐⭐
03private_message私信收发 + 历史查询⭐⭐
04comment评论自动回复 + 点赞⭐⭐
05live_manager直播间管理（弹幕命令/禁言/静音）⭐⭐⭐
06dynamic动态页多 UP 主合并监听⭐⭐
07video_parserQQ 群自动解析 B 站视频链接（含小程序卡片）⭐⭐

github/ — GitHub 平台专属（开发中）

使用 registrar.github.* 平台子注册器。⚠️ GitHub Adapter 尚在开发阶段。

#插件演示功能难度
01hello_worldIssue/PR/Push 基础事件⭐
02issue_botIssue 自动回复机器人⭐⭐

lark/ — 飞书平台专属

使用 registrar.lark.* 平台子注册器和飞书专用事件/API。

#插件演示功能难度
01hello_world群聊/私聊基础响应、LarkPostBuilder 富文本⭐

ai/ — AI 平台

使用 api.ai.* 调用 LLM 提供商 API（Chat / Embeddings / Image Generation）。

#插件演示功能难度
01hello_worldChat Completion、Embeddings、图像生成、参数自动绑定⭐

cross_platform/ — 跨平台操作

同时使用多个平台的子注册器，或通过 Trait 实现跨平台逻辑。

#插件演示功能难度
01multi_adapter双平台启动（QQ+Bilibili）、跨平台命令⭐⭐
02trait_programmingReplyable/HasSender/GroupScoped Trait 编程⭐⭐
03github_qq_bridgeGitHub↔QQ 双向桥接（事件转发/消息映射）⚠️⭐⭐⭐

使用方式

  1. 将任意示例插件文件夹复制到项目根目录的 plugins/ 下
  2. 启动 Bot，插件自动加载
plugins/
├── qq_01_event_registration/   # 从 examples/qq/01_event_registration/ 复制
│   ├── manifest.toml
│   └── main.py
